# 统一约定与第一阶段说明

## 坐标与张量

- 坐标：右手系，x/y 水平、z 向上，单位米；本阶段只处理水平面方向。
- 方位角：从阵列看向声源，+x 为 0°，+y 为 90°。
- 几何 `(M, 3)`；后续时域音频 `(N, M)`；STFT `(F, T, M)`。
- 导向矢量及权重 `(F, M)`；输出 `Y[f,t] = w[f]^H X[f,t]`。
- 参考麦克风固定为第 0 个，导向矢量该通道为 1。
- 线阵存在镜像方向歧义：水平面 θ 与 360°−θ 无法区分。DOA 评测将限制
  线阵方向范围或单独报告歧义，不能把镜像方向直接当作可辨识方向。

## 远场与 DAS

设 u 为指向声源的单位向量，r 为麦克风坐标。
相对时延 τ_m = −(r_m−r_ref)·u/c，导向矢量 a_m(f)=exp(−j2πfτ_m)。
因此正 x 方向声源，在更靠近正 x 的麦克风上相位超前。
DAS 使用 w=a/M；相干目标满足 w^H a=1，空间白噪声下输出噪声功率为输入的 1/M。
该结论依赖平面波、正确方向、单位幅值响应及不相关噪声，不能外推成真实混响语音提升。

4 麦、4 cm 间距的方向图给出三条基础结论：

1. 同样孔径下，4 kHz 主瓣一般比 1 kHz 更窄。
2. 4 cm 对 4 kHz 满足保守的半波长间距条件，c/(2d)=4287.5 Hz。
3. 将间距扩大为 8 cm，在 4 kHz、30° 偏转时会出现与主瓣同高的栅瓣。
   绘图脚本显式标出该方向；栅瓣与线阵的镜像歧义是不同问题。

## 未来评测协议（待下一阶段实现）

SI-SDR 主参考计划使用参考麦克风处的目标直达声，保留传播时延；
混响目标分量同时保存，用来区分抑噪与去混响。两种参考不混入同一结果列。
所有前端共享参考、采样率、裁剪和对齐规则，统一记录算法延迟。
PESQ/STOI 的采样率和许可要求将在接入时核实；缺失指标标注 unavailable，不能填 0。
CER 使用相同 ASR 模型与固定文本归一化；按总编辑距离/总参考字符数聚合。
训练/验证/测试按说话人隔离，干净语音、噪声与仿真种子写入 manifest。
合成信号只用于单元验证，不用于冒充真实语音 ASR 或增强结果。
