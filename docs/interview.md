# 简历与面试表达材料

以下均基于本项目实测；使用前应亲自复现并完成试听，不把脚本运行替代自己的理解。

## 三条简历 bullet

- 搭建可复现的多通道远场语音仿真与评测系统，覆盖 4 麦线阵/6 麦圆阵、3 档混响、点源干扰和扩散噪声；完成 200 条带文本测试语音的六前端对照与 1400 次固定 ASR 解码。
- 实现 DAS、带对角加载的 MVDR、三类 DOA 及掩码协方差 MVDR；自训练 8.3 万参数 GRU，隔离 train/dev/test 说话人与噪声源，完成 20 epoch、单 batch 过拟合与 75 项测试。
- 以 CER 验证增强收益：DAS/oracle MVDR 将基线 37.89% 降至 28.91%/17.27%；完成 20 位说话人、1320 行配对消融，分析神经 MVDR 未超过 DAS 及单通道降噪损害识别的负结果。

## 三分钟讲述稿

我做的是多通道远场语音前端，重点是验证前端是否真的帮助识别，而不只让波形指标好看。我的输入是房间里带混响、点源干扰和扩散噪声的多通道语音，输出是单通道音频，再送入固定的中文 ASR。

数据上，我用原始 AISHELL 测试划分的 200 条带文本语音构建评测集，覆盖 4 麦线阵和 6 麦圆阵，以及多种房间、方向和距离。训练另用原始 train/dev，按说话人和源噪声隔离。每次仿真固定种子，并保存分量、哈希、接收 SNR 和混响估计，避免测试集与训练数据混在一起。

算法分两条线。第一条是传统方法：DAS 使用导向矢量补偿相位，MVDR 在保留目标方向响应的同时压低噪声，加入对角加载避免有限样本协方差病态。第二条是学习方法：参考麦克风的对数功率谱送入轻量 GRU，预测语音掩码，再用语音与噪声掩码估计空间协方差，构造 Souden MVDR。我先检查单 batch 过拟合，再重新初始化做正式训练，并用理想掩码作为诊断参考。

结果里，未处理 CER 是 37.89%，DAS 是 28.91%，已知方向并有纯噪声校准的 oracle MVDR 是 17.27%。神经 MVDR 为 33.37%，没有超过 DAS；同一网络的单通道降噪虽然改善 SI-SDR 和 PESQ，却使 CER 变到 51.85%。这说明训练损失下降、增强指标改善和识别收益不能直接画等号。我的报告保留了十个不一致案例，并把原因写成待验证假设，而不是看到结果就编因果故事。

最后，我做了固定孔径、共享声场的配对消融。20 位说话人的结果显示，混响增加时两种方法都退化；正负二十度导向误差对 MVDR 的平均 SI-SDR 损失比 DAS 大。这个项目让我把阵列模型、数值稳定性、数据隔离和下游指标串到同一套可审计流程里。后续我会优先改进掩码的语音保持能力，并在真实录音和更大说话人覆盖上验证泛化。

## 二十题自问自答

1. **导向矢量的符号是什么？** 方位角指向声源，`tau_m=-(r_m-r_ref)·u/c`，负指数 FFT 下 `a_m=exp(-j2πf tau_m)`；输出统一为 `wᴴX`。
2. **远场假设什么时候失效？** 距离相对孔径不够大时，球面波的幅度与曲率不可忽略。该项目模拟真实 RIR，却以平面波导向，因此有模型失配。
3. **怎样理解空间混叠？** 对给定最高频率，一维均匀阵通常以间距不超过半波长作为避免全视场空间混叠的条件；实际还与视场和几何有关。
4. **为什么逐频点处理？** STFT 把宽带问题近似成窄带问题；窗口长度、混响长度和信号非平稳性决定近似误差。
5. **DAS 为什么除以麦克风数量？** 单位模导向下 `w=a/M`，使 `wᴴa=1`，避免仅因通道数改变目标增益。
6. **MVDR 解怎么来？** 最小化 `wᴴRn w`，约束 `wᴴa=1`，用拉格朗日乘子得到 `Rn^-1 a/(aᴴRn^-1 a)`；实现解线性方程，不显式求逆。
7. **为什么做对角加载？** 有限帧、相干通道和低噪声频点会使协方差病态；按平均通道功率缩放的加载兼顾尺度与稳定性，但过大时削弱自适应抑制。
8. **Oracle 为什么不保证每项指标都最好？** 真实方向和纯噪声段只是额外信息，仍有有限样本、混响失配和参考定义差异；它不是所有非线性指标的数学上界。
9. **纯噪声前缀怎样避免目标泄漏？** 前缀长 0.6 秒，只选窗完整落在其内部且避开初始边缘的 STFT 帧，不把跨越目标起点的帧拿来估计噪声。
10. **扩散噪声怎么生成？** 三维各向同性场的相干矩阵为 `sinc(2fd/c)`，每频点做半正定谱因子分解后施加高斯激励；独立通道白噪声不等于扩散场。
11. **GCC、SRP、MUSIC 有何差异？** GCC 先找各麦对时差再拟合方向；SRP 在候选方向累加相位一致性；MUSIC 分解空间协方差并检查导向与噪声子空间的正交程度。
12. **为什么 DOA 会找到干扰？** 这些实现没有说话人身份条件，默认主导单源。低 SNR、非平稳强干扰和混响可使最大峰对应干扰；线阵还存在镜像歧义。
13. **功率 IRM 与幅度 IRM一样吗？** 不一样。这里标签为 `Ps/(Ps+Pn)`，不是平方根；明确公式比只写 IRM 更重要。
14. **掩码如何变成协方差？** `Rs=sum(m_s X Xᴴ)/sum(m_s)`，噪声同理。掩码误差会把语音能量混进噪声协方差，可能造成目标抵消。
15. **Souden 与给定 steering 的 MVDR 有何关系？** Souden 用 `Rn^-1 Rs/trace(Rn^-1 Rs)` 的参考通道列，不另估显式 DOA；在秩一目标模型等条件下与经典形式相关。
16. **训练为什么先过拟合一批？** 排查标签、维度、梯度和优化链路；通过后重新初始化正式训练。过拟合成功不能证明泛化。
17. **为什么 dev BCE 比 train 低？** 训练有 dropout、随机片段和不同声学条件，验证是整段且关闭 dropout；损失不必按常见直觉排序，仍需核查数据隔离。
18. **为什么增强好但 CER 差？** 感知/波形指标和 ASR 的目标不同，过度抑制可能删除区分音素的线索；应看具体错字与配对干预，不能只凭指标断定原因。
19. **CER 为什么不能平均逐句结果？** 句长不同。正确语料级 CER 是全体插入、删除、替换总数除以参考字符总数，空预测也不能丢弃。
20. **当前最重要的限制与下一步是什么？** 训练说话人少、仅仿真声学、神经性能未胜 DAS、DOA 缺少目标身份信息。下一步扩大训练覆盖、保守掩码/目标保持损失、真实录音测试，并保持 ASR 与测试协议固定。
