# 干净语音与官方 ASR 基准的对应关系

本项目实际解码：200 条原始 AISHELL 测试语音 CER 为 2.66%；
固定 50 条说话人平衡子集 CER 为 1.75%。未按识别结果挑选样本。

官方团队的 [FunAudioLLM 技术报告 v2，表 6](https://arxiv.org/html/2407.04051v2#S4.T6)
列出 SenseVoice-S 在 AISHELL-1 test 上 CER 为 2.96%。该报告的 4.1 节说明对中文进行简体转换和额外文本规范化。
本项目采用 int8 ONNX、固定中文、关闭 ITN、NFKC 和标点/空白移除，且只评估短句子集；
因此 2.66% 与 1.75% 只能作为同一量级的运行健全性检查，不能称为全量基准复现，也不能称为超越官方。

后续严格对齐需要固定同一权重修订、精度、全量测试清单、文本规范化、ITN/LID 与解码参数，
再在相同机器环境重新运行。目前前端比较保持相同 ASR 配置，保证本项目内部可比。
